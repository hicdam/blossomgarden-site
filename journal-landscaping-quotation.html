What to include in a landscaping quotation

Practical guidance for homeowners across Surrey, Sussex and Hampshire.

A useful landscaping quotation should tell you exactly what is being built, what materials are being used and what is not included.

Start with the scope. The quote should describe each area of work clearly: paving, walls, steps, fencing, drainage, lawns, planting, lighting, irrigation or anything else involved.

Materials should be specific. 'Patio paving' is not enough. The quotation should identify the product, size, finish and, where relevant, the laying pattern, jointing method and edge detail.

Ground preparation matters just as much as the visible finish. Excavation depth, sub-base, concrete, drainage layers, soil improvement and disposal of spoil should all be clear.

For planting, the quote should state plant sizes, quantities and whether compost, mulch, staking and watering-in are included.

Labour, machinery, skips, haulage and waste removal should also be accounted for. If access is difficult, make sure any extra handling or lifting requirements have been considered.

A good quotation should identify exclusions and assumptions. It should also set out the payment schedule, programme, VAT position and what happens if hidden conditions are found once work begins.

Before comparing prices, make sure each contractor is pricing the same thing. A cheaper quote is not genuinely cheaper if half the necessary work has been left out.
